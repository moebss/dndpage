4. Datenerfassung auf dieser Website

Google OAuth 2.0 Login

Diese Website bietet optional die Möglichkeit zur Anmeldung mit einem Google-Account an. Wenn Sie sich mit Google anmelden, werden folgende Daten von Google übertragen und bei uns gespeichert:

  • Google User ID (eindeutige Kennung)
  • E-Mail-Adresse
  • Name
  • Profilbild (optional)

Diese Daten werden ausschließlich verwendet, um:

  • Ihren Account zu identifizieren
  • Ihren Story-Fortschritt geräteübergreifend zu speichern
  • Ihre Session zu verwalten

Die Anmeldung ist freiwillig. Sie können die App auch ohne Anmeldung nutzen. In diesem Fall wird Ihr Fortschritt nur lokal in Ihrem Browser gespeichert.

Rechtsgrundlage: Art. 6 Abs. 1 lit. a DSGVO (Einwilligung)

Supabase Datenbank

Wenn Sie sich anmelden, werden Ihre Daten und Ihr Story-Fortschritt in einer Supabase-Datenbank gespeichert (Supabase Inc., San Francisco, USA). Supabase ist DSGVO-konform und speichert Daten verschlüsselt.

LocalStorage

Diese Website nutzt die LocalStorage-Funktion Ihres Browsers, um Story-Fortschritte lokal zu speichern. Diese Daten verlassen Ihren Browser nicht, es sei denn, Sie melden sich an und synchronisieren Ihren Fortschritt.

Server-Log-Dateien

Der Provider der Seiten erhebt und speichert automatisch Informationen in so genannten Server-Log-Dateien, die Ihr Browser automatisch an uns übermittelt. Dies sind:

  • Browsertyp und Browserversion
  • verwendetes Betriebssystem
  • Referrer URL
  • Hostname des zugreifenden Rechners
  • Uhrzeit der Serveranfrage
  • IP-Adresse

Eine Zusammenführung dieser Daten mit anderen Datenquellen wird nicht vorgenommen. Die Erfassung dieser Daten erfolgt auf Grundlage von Art. 6 Abs. 1 lit. f DSGVO.

5. Externe Dienste

Perplexity AI API

Diese Website nutzt die Perplexity AI API zur Generierung von Story-Inhalten. Wenn Sie die Story-Generierung nutzen, werden Ihre Eingaben an Perplexity AI gesendet. Es werden keine personenbezogenen Daten übertragen.

Google Gemini API

Optional werden Bilder mit der Google Gemini API generiert. Hierbei werden nur Story-Prompts, keine personenbezogenen Daten übertragen.
